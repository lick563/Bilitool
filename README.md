- 解析B站视频链接，获取视频、音频资源
- 支持单独提取音频
- 页面简洁，操作简单，开箱即用

## 📌 使用说明
1. 复制B站视频链接
2. 打开在线工具，粘贴链接进行解析
3. 解析成功后，选择视频/音频进行下载
